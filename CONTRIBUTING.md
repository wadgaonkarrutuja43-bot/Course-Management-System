# Contributing to Course Management System

1. Fork or clone the repository and create a feature branch.
2. Follow the existing PHP, MySQL, HTML, CSS, JavaScript and Bootstrap structure and coding conventions.
3. Keep changes small and describe them clearly.
4. Test the affected pages or endpoints locally before opening a pull request.
5. Never commit `.env`, passwords, private keys, tokens, or generated dependency folders.
6. Update `README.md`, `ARCHITECTURE.md` and `CHANGELOG.md` when behavior changes.

## Reporting problems
Include steps to reproduce, expected behavior and actual behavior. Remove personal data from screenshots and logs.
