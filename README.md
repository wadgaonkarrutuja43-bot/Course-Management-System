# 📚 Course Management System

A comprehensive web-based platform designed to streamline course administration, student enrollments, and academic management.

[![Platform](https://img.shields.io/badge/Platform-Web-blue.svg)](https://developer.mozilla.org/)
[![Language](https://img.shields.io/badge/Language-PHP-777BB4.svg)](https://www.php.net/)
[![Database](https://img.shields.io/badge/Database-MySQL-4479A1.svg)](https://www.mysql.com/)

---

## ✨ Key Features

* 👨‍🏫 **Admin Dashboard:** Manage courses, instructors, and student records efficiently.
* 🎓 **Student Enrollment:** Easy registration and course enrollment interface.
* 📖 **Course Catalog:** Clear list of available courses, descriptions, and prerequisites.
* 📊 **Database Integration:** Relational database setup to ensure data integrity and real-time updates.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Backend:** PHP
* **Database:** MySQL
* **Server Environment:** XAMPP
